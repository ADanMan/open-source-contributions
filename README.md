## Избранные работы

- **Telegram Android.** Исправление потери абзацев при вставке текста. На iQOO проверены вставка, положение курсора и отмена. [Патч и результаты](https://github.com/ADanMan/telegram-android-contributions/tree/main/bugs/67474) · [Upstream PR #2270](https://github.com/DrKLO/Telegram/pull/2270)
- **Telegram Android.** Воспроизведение нечитаемого черновика при смене темы на Pixel 8 Pro и повторная проверка после обновления Telegram. [Сравнение версий 13.1.1 и 13.2.1](https://github.com/ADanMan/telegram-android-contributions/tree/main/bugs/67017)
- **Multica.** Предложение сохранить настройки CLI-профиля при повторном подключении. [Upstream PR #10290](https://github.com/multica-ai/multica/pull/10290)
- **Mobilerun.** Исправление очистки временных callbacks при ошибке вызова LLM. [Upstream PR #526](https://github.com/droidrun/mobilerun/pull/526)
