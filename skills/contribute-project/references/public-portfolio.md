# Персональный каталог вклада

Для продолжения работы открой карточку в репозитории проекта. Публичный каталог объединяет ссылки на работы одного автора в разных проектах. Для ADanMan это ADanMan/open-source-contributions. Сохраняй очередь Telegram и доказательства в ADanMan/telegram-android-contributions. Для другого автора или проекта определи репозитории из запроса и проверь remotes.

1. В очереди каждого проекта укажи первоисточник, статус трекера, минимальный сценарий и следующий шаг. Карточки других авторов в очереди сами по себе не дают оснований приписать работу владельцу каталога.
2. В карточке воспроизведения запиши окружение, версию или SHA, шаги, наблюдаемый эффект, сравнение до и после и ограничения. Для Android при нескольких устройствах выбирай serial через adb -s. Для кружков используй telegram-round-video-sync, если установлен.
3. В портфолио добавляй подтверждённые публичные результаты. Для PR проверь автора, целевой репозиторий, номер, состояние и факт merge. Для диагностики или ревью опиши конкретное действие и дай прямую ссылку на отчёт или ревью. Отмечай соавторство. Учитывай собственные проекты отдельно от внешних. Не выдавай работу других авторов за вклад владельца.
4. Чтобы обновить список PR, запусти scripts/update-portfolio.py в корне каталога, проверь diff и дату снимка. Повторное обновление должно заменять старое состояние того же PR. При сбое источника сохрани предыдущий снимок.
5. После теста восстанови настройки, кроме согласованных на период серии. Удали свои временные файлы и дубли архивов. Запиши, какие тестовые сборки и доказательства нужны для открытого PR. При завершении серии проверь их снова. В публичные материалы включай только обезличенные результаты.
